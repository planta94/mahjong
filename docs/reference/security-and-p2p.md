# Security & Serverless P2P Reference

## 1. Host-Authoritative State Sanitization

- Only `HostSession` holds `MatchState` (including `wall` and concealed hands).
- Every guest receives a seat-specific `SessionSnapshot` generated by `getPlayerView(match, seatIdx)`:
  - `wall` is omitted (`wallCount` integer only).
  - Opponents' `hand` arrays are replaced with `null` + `handCount` until `phase === 'handOver'`.
  - Concealed Kongs (`m.concealed`) are masked as `['back', 'back', 'back', 'back']` until `handOver`.
  - Seat authentication tokens (`LobbySeat.token`) are stripped (`token: null`) in all outbound snapshots.

## 2. ESLint & Object-Injection Hardening

- `eslint-plugin-security` (`security/detect-object-injection`) is active across `src/**/*.ts` with **zero warnings** and **zero `eslint-disable` comments**.
- Use `Map<K, V>` (`TILE_SPEC_MAP`, `CODE_INDEX_MAP`, `MODE_PLAYABLE_MAP`, `bySeat` maps) and `Array.prototype.at()` rather than dynamic `obj[key]` or `arr[idx]` bracket indexing.
- Sanitize room codes read from URL query parameters (`?room=`) to alphanumeric uppercase (`<= 8` chars), and clear query strings via `window.history.replaceState()` when leaving a table.
